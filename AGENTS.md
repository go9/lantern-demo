# lantern-demo

Live demo and lantern-ui components reference for [lantern](https://github.com/go9/lantern) and [lantern-ui](https://github.com/go9/lantern-ui).

- **Deploy** is a push to `main`. GitHub Actions builds `ghcr.io/go9/lantern-demo` and deploys the flicker app `lantern-demo` (project `lantern-ui`).
- **Deps:** `lantern` from GitHub (`go9/lantern`); `lantern_ui` from Hex (`~> 0.8.1`).
- **Elixir pin:** 1.18.4 / OTP 28 — see `.tool-versions`.
